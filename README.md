# ☕ Java

> Repositório dedicado ao estudo contínuo da linguagem Java, cobrindo desde conceitos fundamentais e Orientação a Objetos até frameworks modernos como Spring Boot e boas práticas de código.

---

## 🎯 Objetivo

O intuito deste repositório é documentar minha evolução na linguagem Java, servir como material de consulta rápida para o futuro e demonstrar a aplicação prática dos conceitos aprendidos através de exercícios e pequenos projetos.

---

## 🗺️ Trilha de Aprendizado (roadmap.sh)

### 1. 🔤 Learn the Basics (Fundamentos)
- [ ] Basic Syntax & Variables / Scopes
- [ ] Data Types & Type Casting
- [ ] Conditionals (`if`, `switch`)
- [ ] Loops (`for`, `while`, `do-while`)
- [ ] Arrays & Strings / Methods
- [ ] Math Operations & Lifecycle of a Program

### 2. 🧩 Basics of OOP & More about OOP (Orientação a Objetos)
- [ ] Classes, Objects, Attributes & Methods
- [ ] Access Specifiers & `static` Keyword
- [ ] Abstração, Encapsulamento, Herança e Polimorfismo
- [ ] Interfaces, Classes Abstratas & Nested Classes
- [ ] Method Overloading / Overriding & Binding (Static vs Dynamic)
- [ ] Enums, `final` Keyword, Initializer Blocks & Pass by Value/Reference
- [ ] Records & Object Lifecycle
- [ ] Method Chaining, Packages & Annotations

### 3. 📦 Collections Framework & Generics
- [ ] Generics & Generic Collections
- [ ] Array vs ArrayList
- [ ] Set & Map
- [ ] Queue, Stack & Deque
- [ ] Iterator & Optionals

### 4. ⚙️ Conceitos Intermediários e Avançados
- [ ] **Exception Handling:** `try-catch`, Checked/Unchecked exceptions, custom exceptions
- [ ] **Functional Programming:** Lambda Expressions, Functional Interfaces, High Order Functions, Streams API
- [ ] **I/O Operations:** File Operations, Input/Output Streams
- [ ] **Concurrency & Memory:** Threads, Virtual Threads (Java 21+), Java Memory Model, `volatile` keyword
- [ ] **Outros:** Modules, Date and Time API, Regular Expressions, Cryptography, Networking

### 5. 🛠️ Build Tools & Documentation
- [ ] Build Tools: Maven 
- [ ] Documentation: Javadoc

### 6. 🗄️ Database Access & Persistence
- [ ] JDBC (Java Database Connectivity)
- [ ] ORM: Hibernate / EBean
- [ ] Spring Data JPA

### 7. 🧪 Testing (Testes de Software)
- [ ] **Unit Testing:** JUnit 5
- [ ] **Mocking:** Mockito
- [ ] **Integration Testing:** REST Assured / JMeter
- [ ] **Behavior Testing (BDD):** Cucumber-JVM

### 8. 🌐 Web Frameworks & Dependency Injection
- [ ] **Spring / Spring Boot** *(Recomendado)*
